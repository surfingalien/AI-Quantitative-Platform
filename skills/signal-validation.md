# Trading Signal Validation & Verification

## Overview

This skill provides guidance on validating trading signals generated by the AI-Quantitative Platform, ensuring data integrity, and preventing false signals before execution.

## Signal Validation Framework

### Pre-Execution Checks
```python
def validate_signal(signal: dict) -> tuple[bool, list[str]]:
    """
    Comprehensive signal validation before trading.
    Returns: (is_valid, error_messages)
    """
    errors = []
    
    # 1. Data completeness
    required_fields = ['symbol', 'decision', 'confidence', 'price', 'timestamp']
    for field in required_fields:
        if field not in signal:
            errors.append(f"Missing required field: {field}")
    
    # 2. Data types
    if not isinstance(signal.get('confidence'), (int, float)):
        errors.append("Confidence must be numeric")
    if signal.get('decision') not in ['BUY', 'SELL', 'IGNORE']:
        errors.append("Invalid decision value")
    
    # 3. Value ranges
    if not 0 <= signal.get('confidence', -1) <= 10:
        errors.append("Confidence out of range (0-10)")
    if signal.get('price', 0) <= 0:
        errors.append("Price must be positive")
    
    # 4. Logical consistency
    if signal.get('decision') == 'IGNORE' and signal.get('confidence', 0) > 5:
        errors.append("IGNORE decision should have low confidence")
    
    # 5. Timestamp validation
    timestamp = signal.get('timestamp')
    if not is_recent_timestamp(timestamp, max_age_seconds=300):
        errors.append("Signal timestamp too old")
    
    return len(errors) == 0, errors
```

## Common Signal Issues & Fixes

### Issue 1: Stale Data
```python
# ❌ WRONG: Using old price data
if signal['timestamp'] < current_time - timedelta(minutes=10):
    # Execute anyway - DANGEROUS!
    execute_trade(signal)

# ✅ RIGHT: Reject stale signals
if signal['timestamp'] < current_time - timedelta(minutes=5):
    log.warning(f"Signal stale, skipping: {signal}")
    reject_signal(signal)
```

### Issue 2: Data Gaps
```python
# ❌ WRONG: Missing indicator data
if 'rsi_14' not in technical_data:
    # Proceed anyway - RISKY!
    score = calculate_score(technical_data)

# ✅ RIGHT: Require complete data
required_indicators = ['rsi_14', 'macd_value', 'volume']
if not all(ind in technical_data for ind in required_indicators):
    reject_signal("Incomplete technical data")
```

### Issue 3: Extreme Values
```python
# ❌ WRONG: No bounds checking
price = signal.get('price')
quantity = calculate_position_size(price)

# ✅ RIGHT: Validate ranges
if not (0 < signal['price'] < market_cap):
    reject_signal(f"Price {signal['price']} outside valid range")
if not (min_volume <= signal['volume'] <= max_volume):
    reject_signal(f"Volume {signal['volume']} outside expected range")
```

## Real-Time Monitoring

### Signal Stream Health Check
```python
def monitor_signal_health(signals: List[dict], window_minutes=60):
    """Monitor signal quality over time."""
    
    recent_signals = [s for s in signals 
                     if (now - s['timestamp']).total_seconds() < window_minutes * 60]
    
    if not recent_signals:
        alert("No signals in last hour - system issue?")
        return False
    
    # Calculate metrics
    avg_confidence = mean([s['confidence'] for s in recent_signals])
    buy_ratio = len([s for s in recent_signals if s['decision']=='BUY']) / len(recent_signals)
    
    # Validation
    if avg_confidence < 4:
        alert("Low average confidence - check indicators")
    if buy_ratio > 0.8:
        alert("Too many BUY signals - check for bias")
    if buy_ratio < 0.05:
        alert("Too few BUY signals - system may be broken")
    
    return True
```

## Implementation Guidelines

### Step 1: Setup Validation Pipeline
```python
from validation import SignalValidator

validator = SignalValidator(
    min_confidence=6,
    max_age_seconds=300,
    required_fields=['symbol', 'decision', 'confidence', 'price']
)
```

### Step 2: Validate Before Execution
```python
# Receive signal from webhook
signal = receive_webhook_payload()

# Validate immediately
is_valid, errors = validator.validate(signal)

if not is_valid:
    log.error(f"Signal rejected: {errors}")
    return False

# Proceed to execution
```

## Troubleshooting

### "Signal rejected: Missing required field"
**Cause:** Webhook payload incomplete  
**Fix:** Check webhook source, ensure all fields included

### "Signal rejected: Timestamp too old"
**Cause:** Processing delay  
**Fix:** Reduce queue processing time, check system load

### "Low average confidence"
**Cause:** Market conditions, weak indicators  
**Fix:** Review technical indicators, check market regime

### "Too many BUY signals"
**Cause:** Bias in scoring, market euphoria  
**Fix:** Adjust weights, add mean reversion filter
